# Horizon Promotion Gate

A later horizon is closed until every applicable item is complete.

- [ ] Owner-approved ADR identifies the exact module and new state.
- [ ] Current horizon exit evidence is complete and reproducible.
- [ ] Customer demand or design-partner evidence is attached where required.
- [ ] Legal gate is signed where regulated activity is involved.
- [ ] Safety/provider gate is signed where autonomous vehicles or physical automation are involved.
- [ ] Security and threat-model review is complete.
- [ ] Pricing status and billing entitlement state are updated.
- [ ] `config/scope/module_states.yaml` is updated.
- [ ] Roadmap and phase prompt are updated.
- [ ] New tests prove prior disabled-state assumptions still hold.
- [ ] Rollback and kill-switch behavior are documented and tested.
- [ ] Reviewed PR and exact promotion SHA are recorded.

A phase prompt, feature flag, schema, prototype, or successful simulation does not satisfy this gate by itself.

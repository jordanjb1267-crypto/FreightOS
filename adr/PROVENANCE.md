# Provenance

Generated from **FreightOS Production Handoff v1.2**
(`docs/production-handoff/v1.2/`), which is immutable and byte-pinned by `SHA256SUMS.txt`.

Do not hand-edit files in this directory. Run `pnpm sync:handoff` to regenerate, then review the
diff. `pnpm validate:provenance` runs in CI and fails on any unreviewed drift — in either
direction, and including changes to an authorised override.

Intentional divergence is expressed as a declared `override` in `handoff-provenance.json` naming
the ADR that authorises it. There is no other sanctioned way to differ from the handoff.

Operational copy of the handoff `adr/` tree (0001-0013), plus ADRs 0014-0018 authored in Phase 0 and
ADRs 0019-0025 authored in Phase 1. The new ones record the owner rulings and authorise every
divergence from the handoff.

Only 0001-0013 are generated copies tracked in `handoff-provenance.json`. ADRs 0014 and above are
original work and are not regenerated by `pnpm sync:handoff`; editing them is expected, and the
provenance check does not read them.

| Range | Origin | Records |
| --- | --- | --- |

| 0014-0018 | Phase 0 | Repository location, legal model, infrastructure baseline, reference DDL, autonomy ceiling |
| 0019-0025 | Phase 1 | Operating-context boundaries, control-plane access, common record fields, geospatial representation, X12 licensing, package paths, detention mechanism |

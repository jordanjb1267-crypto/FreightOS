# UN/CEFACT Alignment Profile

## Scope

Use UN/CEFACT reference data models and code lists as semantic inputs for multimodal and buy-ship-pay concepts.

## Rules

- maintain mapping metadata to the relevant model/version;
- preserve codes and issuing agencies;
- identify fields with no exact canonical equivalent;
- avoid redefining internationally established concepts without justification;
- use the mappings to support cross-modal documents and government/trade interfaces.

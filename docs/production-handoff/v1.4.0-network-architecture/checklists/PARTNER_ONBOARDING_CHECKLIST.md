# Partner Onboarding Checklist

- [ ] Legal organization and contacts verified
- [ ] Identity/credential method approved
- [ ] Represented tenants and roles documented
- [ ] Data-sharing scope and purpose approved
- [ ] API/event/EDI profile selected
- [ ] Sandbox access issued
- [ ] Synthetic conformance tests passed
- [ ] Negative authorization tests passed
- [ ] Rate limits and quotas agreed
- [ ] Webhook/signature/replay controls verified
- [ ] Retry and reconciliation tested
- [ ] Security and incident contacts confirmed
- [ ] Production flags and kill switch assigned
- [ ] SLO/support agreement documented
- [ ] Production credentials issued only after approval

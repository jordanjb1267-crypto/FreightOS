# Production Readiness Review

## Ownership and scope

- [ ] Service/domain owner named
- [ ] Criticality class assigned
- [ ] Dependencies and vendor tiers documented
- [ ] Threat model approved

## Security and privacy

- [ ] Identity and authorization model tested
- [ ] Tenant isolation proven across all storage/retrieval paths
- [ ] Data inventory/classification complete
- [ ] Secrets and key access controlled
- [ ] Audit and privileged access operational

## Reliability

- [ ] SLIs/SLOs and error-budget policy configured
- [ ] Capacity and load test complete
- [ ] Dependency failures and degraded modes tested
- [ ] Queue/backpressure/timeout/circuit-breaker behavior tested
- [ ] Alerts and runbooks validated

## Delivery and recovery

- [ ] Signed/provenanced artifact pipeline
- [ ] Canary and rollback proven
- [ ] Migration strategy proven
- [ ] Backup and restore test complete
- [ ] Regional/cell recovery appropriate to launch stage

## Operations

- [ ] On-call and escalation path
- [ ] Incident severity and communication process
- [ ] Synthetic monitoring
- [ ] Reconciliation and manual correction workflow
- [ ] Known risks/exceptions have owners and expiration

## Launch approval

- [ ] All R3/R4 gates pass or have approved finite exception
- [ ] No unsupported security/compliance/availability claim
- [ ] Owner approval recorded

# Brokerage Legal Gate

All items must be completed and signed before production Brokerage Mode.

- [ ] Brokerage legal entity formed
- [ ] FMCSA registration verified
- [ ] BMC-84 or qualifying BMC-85 verified
- [ ] $75,000 qualifying financial security verified
- [ ] BOC-3/process agent verified
- [ ] Authority monitoring implemented
- [ ] Shipper-broker agreement approved
- [ ] Broker-carrier agreement approved
- [ ] Carrier-agent/dispatch agreements approved
- [ ] Required record fields and retention verified
- [ ] Separate bank accounts configured
- [ ] Separate billing and ledger configured
- [ ] Claims procedure approved
- [ ] Financial failure/insolvency runbook approved
- [ ] Fee disclosures approved
- [ ] Insurance reviewed
- [ ] State/local requirements reviewed
- [ ] Automation boundaries approved by counsel
- [ ] Operations trained
- [ ] Audit export tested
- [ ] Kill switch tested
- [ ] Owner signature
- [ ] Counsel signature
- [ ] Compliance signature

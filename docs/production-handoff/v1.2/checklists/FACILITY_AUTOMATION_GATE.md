# Facility Automation Gate

Policy-bounded FacilityOS execution may be enabled only when:

- [ ] Facility operator contract and authority are documented.
- [ ] Facility roles and delegated approval scopes are configured.
- [ ] WMS/YMS/WES/ERP sources and data ownership are mapped.
- [ ] Gate, yard, dock, calendar, capacity, and restriction data are verified.
- [ ] Physical-motion and safety-control boundary tests pass.
- [ ] Appointment, credential, detention, custody, and discrepancy state machines pass.
- [ ] Human override and facility kill switches pass.
- [ ] Stale capacity or readiness data fails safely.
- [ ] Cross-tenant and cross-facility isolation tests pass.
- [ ] A3 approval evidence precedes A4 promotion.
- [ ] Facility operator, security, and operations signoffs are recorded.

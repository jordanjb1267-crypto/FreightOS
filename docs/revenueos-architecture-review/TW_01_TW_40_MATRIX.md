## The one FAIL

**TW-17** is the package's own central invariant, contradicted by its own artifacts in three
independent ways (undefined terminals, undefined `HOLD` failure sink, unbooked owners). Every other
Twin shortfall is an absence; this one is a contradiction, and it is the single most important thing
to fix before any Twin implementation begins.

## Blockers among TW gates

1. **TW-17** — single accountable owner is contradicted by the shipped graphs.
2. **TW-03 / TW-11** — no fact-authority binding, and the conflict default (`HOLD`) is unowned.
3. **TW-28** — no channel of any kind reaches a non-native counterparty.
4. **TW-16 / TW-38** — no WorkUnit and no application tier, so no human can use the Twin.
5. **TW-08** — echo suppression absent; required before any write-back.

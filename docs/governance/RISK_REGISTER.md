# Risk Register

Required by `02_GOVERNANCE_AND_NON_REGRESSION.md:5-17`. Did not exist before Phase 0.

Severity is likelihood × consequence for the Horizon 1 build specifically, not for the eventual
platform. Review at every phase exit gate.

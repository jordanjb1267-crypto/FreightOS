# Open Question Register

**Status:** Current as of the Phase 1 owner rulings, 2026-08-04
**Companion to:** `docs/governance/RISK_REGISTER.md`. A risk is something that could go wrong; an
open question is something not yet decided or not yet supplied. They are tracked separately so
that "we have not decided" is never filed as "we have mitigated".

Reviewed at every phase exit gate.

## Status legend

- **Resolved** — an owner ruling or artifact answers it. Kept for traceability.
- **Open, non-blocking** — Phase 1 proceeds; the answer changes a later phase or a tenant's
  behaviour, not the build.
- **Open, blocking** — named work cannot start or merge until answered.

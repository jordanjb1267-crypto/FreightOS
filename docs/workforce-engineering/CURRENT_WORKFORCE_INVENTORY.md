## Headline

The repository is a **governed platform substrate**, not a workforce. What exists and is tested: the computed autonomy ceiling and its CI clamp; a fail-closed legal-class × operating-context capability matrix (application half complete, database half for 3 of 12 resource groups); most-restrictive-wins kill-switch resolution with a seeded standing suspension of `autonomous_mobility`; identity, organization hierarchy, permissions and non-weakening policy inheritance; an append-only, non-forgeable audit ledger and an append-only network event journal; N1–N7 network layers up to an idempotent transport intent and a brokered external-transport permit model; `FORCE` row-level security across 16 migrations; database-enforced human approval points (cluster bootstrap, authority convergence, control-plane `admin.*` with purpose gates, authenticated operator principal, verified actor binding). What does **not** exist: any LLM call, prompt, model gateway client, agent loop, tool registry or dispatcher; any supervisor/orchestrator; any workflow engine, queue consumer, outbox producer/consumer or worker daemon; any HTTP client or egress (CI-enforced at zero); any freight-domain table (dispatch, load, shipment, appointment, facility); any brokerage, shipper, facility, RigDesk or communications code; any exception/incident model; any reconciliation process; any `evals/` directory (all 32 manifests point at one), simulation harness, fixture corpus or mutation testing. Of the v1.8 catalog's 76 jobs, **0 are implemented**; 24 have a declared registry manifest, 52 do not; 7 manifests (autonomous mobility) map to no job.
